## 🚀 Cómo Usar

### Leer historias
1. Abre la página
2. Explora las historias en la galería
3. Filtra por categoría con los chips de colores
4. Busca por palabra clave en la barra de búsqueda
5. Haz clic en "Leer historia" para abrirla en un modal

### Publicar tu historia
1. Haz clic en el botón "✍️ Publicar"
2. Completa el formulario con:
   - Título
   - Tu nombre o seudónimo
   - Categoría
   - El texto de tu historia
3. ¡Listo! Tu historia aparecerá en la galería

## 💾 Datos y Privacidad

- Las historias se guardan en **localStorage** de tu navegador
- **No se envía información a ningún servidor**
- Solo tú tienes acceso a tus historias en ese dispositivo
- Si limpias los datos del navegador, se perderán las historias guardadas
